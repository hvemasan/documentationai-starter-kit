---
title: "Delete a help collection"
description: "Soft-delete a help collection. Cascades to its categories and every article inside them."
---

Soft-deletes a help collection. The collection disappears from your dashboard and public help center, but the row is retained and its slug is freed for reuse.

<Callout kind="danger">
  **This cascades.** Deleting a collection also soft-deletes every category inside it, and every article inside those categories — plus any article filed directly in the collection. There is no undo through the API.
</Callout>

## Endpoint

```
POST https://api.productbridge.io/api/external/v1/help-collections/delete
```

## Arguments

<ParamField body="api_key" param-type="string" required="true" deprecated="false">
  Your organization's public API key. See [Authentication](/api-reference/authentication).
</ParamField>

<ParamField body="collection_id" param-type="string" required="true" deprecated="false">
  UUID of the collection to delete. Must belong to your organization.
</ParamField>

## Returns

```json
{ "success": true }
```

## Checking the blast radius first

Because the cascade is silent, call [List categories](/api-reference/help-categories/list) scoped to the collection, and [List articles](/api-reference/help-articles/list) with the same `collection_id`, before deleting. The article list with `collection_id` covers everything in the collection — articles filed directly in it *and* those in its categories — so it gives you the full count in one call.

To keep the content, move it first: [update each category](/api-reference/help-categories/update) with a different `collection_id`, and [re-file direct articles](/api-reference/help-articles/update) elsewhere.

## Errors

| Status | Body | Cause |
|---|---|---|
| `401` | `{"detail":{"error":"invalid api_key"}}` | Missing / unknown / inactive `api_key`. |
| `403` | `{"detail":{"error":"The Help Center is not enabled on your current plan..."}}` | Your plan does not include the `knowledgebase` feature. |
| `404` | `{"detail":{"error":"help collection not found"}}` | No such collection, it was already deleted, or it belongs to another organization. |
| `422` | Validation error envelope | `collection_id` missing or not a valid UUID. |

See [Errors](/api-reference/errors) for the full envelope shape and a recommended client-side handler.
